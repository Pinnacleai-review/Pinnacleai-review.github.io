# Pinnacle AI 量化投資系統網站

本專案為純 HTML、CSS、JavaScript 靜態網站，可直接部署至 GitHub Pages。

## 部署方式

1. 將 ZIP 解壓縮後的全部檔案放到 GitHub 儲存庫根目錄。
2. 把原始圖片上傳至 `images/` 資料夾，檔名必須與 `images/README.md` 完全一致。
3. 在 GitHub 儲存庫的 Settings → Pages 中，選擇從主要分支根目錄部署。
4. 部署後檢查首頁、五篇文章、FAQ、favicon、圖片與行動版選單。

網站正式網址設定為：`https://Pinnacleai-review.github.io/`

## 主要檔案

- `index.html`：首頁
- `about.html`：系統理念與架構
- `insights.html`：文章列表
- `insight-1.html` 至 `insight-5.html`：五篇獨立長文
- `faq.html`：20 條常見問題
- `contact.html`：前端聯絡表單
- `css/style.css`：全站共用樣式
- `js/main.js`：導覽、動畫與表單互動
- `sitemap.xml`、`robots.txt`：搜尋引擎檔案

## 聯絡表單說明

GitHub Pages 沒有後端服務，因此表單不會在網站上儲存或寄送資料。按下提交按鈕後，網站會呼叫訪客裝置上的電子郵件應用程式並填入整理好的內容。
